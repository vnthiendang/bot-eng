      Cách vận hành Discord Bot & Deploy Vercel đơn giản nhất

      Cách 1: Discord Bot thuần túy (Tương tác 100% trong khung chat)

      1. Tạo Bot tại Discord Developer Portal → bật Message Content Intent trong mục Bot.
      2. Copy file .env.example thành .env, điền GEMINI_API_KEY, DISCORD_BOT_TOKEN, DISCORD_CLIENT_ID và DISCORD_CHANNEL_ID.
      3. Chạy lệnh npm start (chạy cả Web UI + Bot) hoặc npm run bot.
      4. Trong Discord: gõ + resilient để thêm từ, gõ thẳng câu tiếng Anh để sửa lỗi, hoặc dùng /write, /quiz, /family, /stats.
      5. Bot tự động nhắn thử thách lúc 08:00 sáng và nhắc giữ Streak lúc 21:00 tối mỗi ngày.

      Cách 2: Deploy Vercel miễn phí + Discord Webhook

      1. Đưa thư mục vocab-daily lên GitHub rồi import vào Vercel (hoặc chạy npx vercel).
      2. Thêm biến môi trường GEMINI_API_KEY (và DISCORD_WEBHOOK_URL nếu muốn) trong cài đặt Vercel Project.
      3. Mở link Vercel trên điện thoại, thêm ra màn hình chính để luyện tập mọi lúc và bấm nút gửi thử thách sang kênh Discord cá nhân.
